# Project RoleMap

Single-user, browser-based RACI matrix and role-mapping tool for project managers.

## Features
- **Role mapping per project** — roles vary by project; one person can play multiple roles; a role can stay blank
- **RACI matrix** — click to cycle R → A → C → I → clear, with rule checks (exactly one Accountable per task, at least one Responsible)
- **Customer Point of Contact** — external stakeholder role pre-seeded: who you speak to about product deliverables, and the channel from whom feedback is collected
- **Audit trail** — every change is timestamped and logged for historical reference
- **Exports** — Excel (.xlsx: color-coded matrix, roles & people, audit log) and PNG image
- **Backup & restore** — JSON backup file; hand the app to someone and they start fresh, or import your backup to continue where you left off
- **Zero dependencies** — one index.html, no build step, no server

## Run it
Open `index.html` in any modern browser. Data is stored locally in your browser (localStorage) — nothing is sent anywhere.

## Deploy on GitHub Pages
Repository **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Live at `https://<username>.github.io/project-rolemap/`.
